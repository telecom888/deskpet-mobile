# 设置页面规划与实现

设置主页面负责展示入口与当前配置摘要，具体参数放入二级页面。入口按“角色与桌面”“对话与声音”“应用信息”三组排列；API 密钥不出现在摘要中。

## 页面分配

| 主页面分组 | 二级页面 | 卡片与设置项 |
| --- | --- | --- |
| 角色与桌面 | 角色与外观 | 角色选择：佩丽卡、彩叶、明日奈、辉夜、白子；悬浮窗尺寸：宽度、高度 |
| 角色与桌面 | 桌面交互 | 桌面显示：启用悬浮窗、AI 回复气泡、气泡显示时长、视频声音；待机互动：随机微笑与概率 |
| 对话与声音 | AI 服务 | 连接配置：API 地址、密钥、模型；生成参数：Temperature、Max Tokens；思考模式：开关与请求协议 |
| 对话与声音 | 人设与对话 | 人设与记忆：系统提示词、多轮上下文；思考过程显示：默认折叠；主动搭话：频率、自定义最小和最大间隔 |
| 对话与声音 | 语音合成 | 播放方式：AI 回复后生成并播放；服务配置：MiMo / 自定义、API 地址、独立密钥、模型；参考音频 / 音色：MiMo 样本或自定义音色 ID |
| 应用信息 | 关于与开源 | 项目地址、MIT 代码许可、角色 WebM 素材的单独授权说明 |

“思考模式”决定请求是否带思考参数，归入 AI 服务；“默认折叠思考过程”只影响阅读方式，归入人设与对话。视频原声位于桌面交互，合成语音位于语音合成。

## 导航与排版

- 主页面采用带图标、标题、配置摘要与箭头的入口行；二级页面采用统一圆角卡片。
- 标题栏显示当前页面名称。标题栏返回和系统返回行为一致：二级页面先返回设置主页面。
- 进入和返回使用方向相反的滑动、淡入淡出动画。
- 每个页面独立保存滚动位置，返回不会重置到顶部。页面与设置草稿支持配置变化恢复。
- 使用可滚动内容与输入法避让，底部固定“保存设置”按钮和保存状态，无需滚动到表单底部。

## 保存与选项收纳

- 沿用现有偏好键与默认值，跨二级页面保留草稿，底部按钮一次保存所有修改。
- 返回二级页面不触发保存。离开设置时若有未保存修改，提供“保存并退出”“继续编辑”“放弃更改”。
- 关闭 TTS 时隐藏服务与音色配置；关闭思考模式时隐藏协议；关闭回复气泡时隐藏时长；关闭随机微笑时隐藏概率；主动搭话选择“自定义”时才显示区间输入。
- 自定义主动搭话间隔在保存时校验，最小值不能大于最大值。
- 角色仍为单选，TTS 密钥仍独立于聊天密钥，所有现有功能保留。
- 重新选择参考音频时先保存在草稿文件中，点击保存后才替换已保存的音色样本；放弃更改不会覆盖原参考音频。

## 验收

构建确认 Kotlin 与 Compose 页面可编译。设备上应检查：六个入口、二级页面往返、页面旋转、草稿与滚动位置恢复、固定保存按钮、未保存退出提示、音频选择返回，以及原有设置保存后仍能被桌宠服务读取。
