# 双击聊天窗口与时间戳

## 两种显示方式

入口：设置 → 桌面交互 → 双击聊天窗口。选择后点击底部“保存设置”。

| 样式 | 排布 |
| --- | --- |
| 跟随角色 · 紧凑弹窗 | 窄卡片显示在角色附近，靠近屏幕边缘或键盘时调整到可用范围内 |
| 屏幕底部 · 聊天卡片 | 水平居中，左右各留 16 dp；最大宽度 480 dp，键盘弹起后显示在键盘上方 |

默认采用底部卡片。两种方式共用主题和交互：24 dp 圆角、角色名称与头像、关闭按钮、圆角多行输入区和发送按钮。跟随系统浅色 / 深色及 Android 12 以上的动态配色，淡入淡出与短距离滑动约 220 ms。

角色头像从待机 WebM 提取缩略图并缓存；无法解码时使用角色名称首字占位。输入默认两行，紧凑模式最多四行，底部卡片最多六行，超出后滚动。空白内容禁止发送；回车换行，外接键盘 Ctrl+Enter 发送。

返回键先收起键盘，再关闭窗口。关闭按钮或点击卡片外的背景收起窗口。未发送的草稿按角色保存，关闭、重新打开或旋转屏幕后可继续编辑。发送成功提交到桌宠服务后关闭窗口；请求失败时恢复原消息草稿，如果用户已输入新的草稿，则保留新草稿。未配置 AI 服务时提供直接进入 AI 服务设置的入口。

聊天输入通过独立的透明 Activity 展示，桌宠与回复气泡仍由原服务管理。统一使用系统栏和输入法 Insets 计算可用空间，紧凑模式根据角色位置定位，底部模式靠下对齐。

两种窗口均提供“历史”入口，可查看记录、选择主对话、新建和删除；操作规则见 [对话历史与主对话](对话历史与主对话.md)。

## 发送当前时间给模型

入口：设置 → 人设与对话 → 对话时间 → 发送当前时间给模型。默认关闭，保存后生效。

开启时，每次用户消息及主动搭话请求都会根据设备当前时间生成一条临时 system 消息，例如：

```text
当前现实时间：2026-09-26T15:30:00+08:00；时区：Asia/Shanghai。
```

实际内容还说明这是设备现实时间，故事内时间以用户设定为准。格式为 ISO 8601，包含年月日、时分秒、UTC 偏移和系统时区 ID；会根据请求日期计算夏令时。

时间消息与人设、历史记录、用户正文分别传递，不修改用户正文，不写入多轮历史，也不送入 TTS。关闭开关后不附加时间信息。该选项不控制界面时间显示，设备时间是否准确由系统设置决定。

## 验证

请求组装测试覆盖关闭时无时间、跨日期与时区偏移、夏令时、用户正文和历史不被改写，以及主动搭话请求。构建验证 Debug / Release；卡片位置、键盘切换、主题、草稿和系统返回需在设备上验证。
