项目代码和文档采用根目录的 [MIT 协议](../LICENSE)。角色 WebM 素材的授权范围见 [ASSETS.md](../ASSETS.md)，不属于 MIT 授权内容。

## 角色

设置采用分组入口与六个二级页面，完整选项分配、导航和保存规则见 [设置页面规划与实现](设置页面规划.md)。角色在“角色与外观”，聊天接口在“AI 服务”，系统提示词与主动搭话在“人设与对话”，音频服务在“语音合成”，悬浮窗行为在“桌面交互”。

设置页可在佩丽卡、彩叶、明日奈、辉夜、白子之间选择。素材目录 `E:\无用文件\素材\res` 标注为**白子**。每个角色有待机、说话、微笑、拖动四段 WebM，应用同一时间只显示所选的一个角色。新选择在保存设置并返回桌面后生效。

## 语音合成

打开“AI 回复后生成并播放语音”后，应用等待完整的文本回复，再发起一次非流式 TTS 请求，得到音频后播放。思考过程不会送入 TTS；TTS 失败时保留文字回复。语音播放期间会暂时静音角色视频。

默认服务为 MiMo `mimo-v2.5-tts-voiceclone`，地址为 `https://api.xiaomimimo.com/v1`。需要单独填写 MiMo API Key，选择一段 mp3 或 wav 参考音频，大小不超过 7 MB，以保证 Base64 后不超过接口的 10 MB 限制。官方示例只上传音频样本，不要求对应文字。音频会复制到应用私有目录，调用时编码为 Data URL；设置项中仅保存本机路径。

“自定义 OpenAI 兼容 TTS”使用 `POST {API 地址}/audio/speech`，请求包含 `model`、`input`、`voice`、`response_format: wav`，响应应为 WAV 音频字节。此协议不适用于其它自定义接口格式。

参考：[MiMo-V2.5-TTS 官方文档](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。

## 思考过程

“开启思考模式”会按所选协议在聊天请求中添加 `reasoning_effort: medium` 或 `enable_thinking: true`。所用模型及服务端必须支持对应参数。返回的 `reasoning_content`、`reasoning` 字段以及正文中的 `<think>…</think>` 会作为思考过程显示；最终回答单独显示、进入多轮历史并用于语音合成。“默认折叠思考过程”只控制显示方式，不影响是否请求模型思考。

## 构建

本项目使用 Android SDK 35、Gradle 8.7 和 Android Gradle Plugin 8.5.1。构建环境复用上一项目的 `D:/Android/Sdk`、`D:/.gradle`。本机的 `local.properties` 仅保存 SDK 路径且不提交到 Git。依赖优先从阿里云 Maven 镜像下载。
